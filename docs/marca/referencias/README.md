# Referências de branding: dither e meio-tom

Imagens de referência da linguagem visual dither/halftone do Novelo, em 4096 × 2913 px.
Estão em **WebP sem perdas** (verificado: pixels idênticos aos PNG originais, 47 726 592 bytes de RGBA cada).

| Ficheiro | Uso |
| --- | --- |
| `dither-montanha-dourado.webp` | Fotografia com meio-tom duotone dourado e verde: hero e capas |
| `dither-dunas-areia.webp` | Degradé de densidade em areia e verde-escuro: fundos de secção |
| `dither-campo-verde.webp` | Degradé monotone verde sobre branco: painéis, login e OG image |

Para abrir como PNG: `dwebp ficheiro.webp -o ficheiro.png` (`brew install webp`).
A linguagem e o gerador ficam documentados em `docs/marca/linguagem-dither.md` e `scripts/brand/`.
